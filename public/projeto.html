05 — POR TRÁS DO PROJETO

Uma eleição que
não depende só
da internet.

O Voz Ativa foi construído para demonstrar arquitetura offline-first: interface, Service Worker, armazenamento local, API Express e Supabase trabalhando juntos.

FRONT-END

HTML + CSS + JS

Várias páginas independentes, navegação tradicional, layout responsivo e interface com identidade visual própria.

PWA

Service Worker

Os arquivos essenciais são colocados em cache para que a navegação continue disponível sem conexão.

BACK-END

Node + Express

A API centraliza a leitura das chapas, registro dos votos e sincronização das operações pendentes.

DATABASE

Supabase

PostgreSQL armazena candidatos, propostas e votos. Uma restrição impede duas votações da mesma sessão.

HTML / CSS / JS→Service Worker→Express API→Supabase→PostgreSQL
